# html-clock
single html file clock

## 预览页面：[https://xiaokuncai.github.io/html-clock/](https://xiaokuncai.github.io/html-clock/)

# 网页时钟 - 功能清单
> 单文件HTML网页时钟，适配树莓派7寸DSI屏

## ✨ 功能清单
### 【时间】
- 24小时制 时/分/秒，秒数可隐藏

### 【日期】
- 公历 + 农历 + 星期 + 节气

### 【天气】天津 · open-meteo API
- 实时温度（取整）
- 今日 + 未来 2 天预报
- 每15分钟对齐刷新（0/15/30/45分）
- 请求失败时整行隐藏

### 【图标】4套可选
- Weather Icons（字体·青色，默认）
- 内置彩色（SVG）
- Weatherbit（图片）
- 和风天气（字体·白色）

### 【字体】
- 自动检测系统等宽字体
- 像素级去重，菜单显示 `0123456789` 预览

### 【亮度】10档（100%–10%）
- 白天60% / 夜间20%
- 夜间自动调暗（22:00–06:00）
- 手动调整只影响当前时段

### 【显示开关】
秒 / 日期 / 天气 / 夜间模式

### 【节日倒计时】公历6项 + 农历9项
- 公历：元旦、妇女节、劳动节、儿童节、建军节、国庆节
- 农历：春节、元宵、端午、七夕、中元、中秋、重阳、腊八、除夕
- 当日显示「今日XX」，30天内显示「距XX N天」
- 节日优先级高于节气

### 【防烧屏】
像素漂移（每30分钟 ±4px）

### 【全屏】
按钮 / 双击 / F 键

### 【快捷键】
- `F`：全屏
- `H`：切换秒显示
- `D`：切换日期显示
- `W`：切换天气显示
- `Esc`：关闭菜单

### 【鼠标】
3.5秒无操作自动隐藏

### 【持久化】
偏好设置保存在 `localStorage`
> 清除浏览器数据后会恢复代码默认值

### 【适配】
树莓派 + 7寸DSI屏，安全区适配
