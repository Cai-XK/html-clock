# html-clock
single html file clock
时钟 · 功能清单
──────────────
【时间】24 小时制 时/分/秒，秒可隐藏
【日期】公历 + 农历 + 星期 + 节气
【天气】天津 · open-meteo API
  · 实时温度（取整）
  · 今日 + 未来 2 天预报
  · 每 15 分钟对齐刷新（0/15/30/45 分）
  · 请求失败时整行隐藏
【图标】4 套可选
  · Weather Icons（字体·青色，默认）
  · 内置彩色（SVG）
  · Weatherbit（图片）
  · 和风天气（字体·白色）
【字体】自动检测系统等宽字体
  · 像素级去重，菜单显示 0123456789 预览
【亮度】10 档（100%–10%）
  · 白天 60% / 夜间 20%
  · 夜间自动调暗（22:00–06:00）
  · 手动调整只影响当前时段
【显示开关】秒 / 日期 / 天气 / 夜间模式
【节日倒计时】公历 6 + 农历 9
  · 公历：元旦、妇女节、劳动节、儿童节、建军节、国庆节
  · 农历：春节、元宵、端午、七夕、中元、中秋、重阳、腊八、除夕
  · 当日显示「今日XX」，30 天内显示「距XX N天」
  · 节日优先于节气
【防烧屏】像素漂移（每 30 分钟 ±4px）
【全屏】按钮 / 双击 / F 键
【快捷键】F 全屏，H 秒，D 日期，W 天气，Esc 关菜单
【鼠标】3.5 秒无操作自动隐藏
【持久化】偏好保存在 localStorage
  · 清除浏览器数据后会恢复代码默认值
【适配】树莓派 + 7 寸 DSI 屏，安全区适配

【部署提示】
开机全屏自启（Chromium Kiosk）：
编辑 ~/.config/lxsession/LXDE-pi/autostart，加入：
@chromium-browser --kiosk --noerrdialogs --disable-infobars file:///home/pi/clock.html

【修改城市】
1. HTML 里搜索 <span class="wcity">天津</span> 改成城市名
2. JS 里搜索 var TIANJIN = { lat: 39.0842, lon: 117.2009 };
   把经纬度改成你的城市坐标
